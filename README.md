# Inmobi
El proyecto consiste en una plataforma digital inmobiliaria enfocada en resolver barreras estructurales de acceso a la vivienda, promoviendo la transparencia, la equidad en precios y la inclusión económica y legal en el sector inmobiliario.

##  Metodología de Trabajo: Kanban
Al tratarse de un equipo pequeño, ciclos rígidos o reuniones excesivas generan sobrecarga. Kanban permite priorizar y responder a cambios de forma continua.

## Arquitectura de Software: Cliente - Servidor
El sistema se diseña bajo un modelo desacoplado Cliente - Servidor, garantizando la separación estricta entre la interfaz de usuario, la lógica de negocio y el almacenamiento de datos.
